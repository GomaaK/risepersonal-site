# Rise Personal — Website

Static single-page site for **Rise Personal**, a personal branding agency in Dubai, UAE.

- Live: https://gomaak.github.io/risepersonal-site/
- Stack: one `index.html`, inline CSS, no frameworks, no JS dependencies
- Design: navy/ink + warm sand/ivory + muted gold; serif display / sans body; CSS-only scroll reveals (graceful fallback); logical properties throughout (Arabic-ready)
- Sections: sticky nav → Hero → About → Services (4) → Why Choose (4 pillars) → Process (4 steps) → Contact → Footer
